## ❓ Frequently Asked Questions

### Is this safe to use?
Yes. The tool is just HTML, CSS, and JavaScript code. It runs in your browser and cannot access your computer or game files. It does not connect to any servers or collect any data.

### Will I get banned for using this?
No. Crosshair codes are part of the game's official settings. You are simply generating random values for settings that already exist in the game. This is identical to manually changing your crosshair in the settings menu.

### How do I paste the code into the game?
Press the `~` key (tilde key, above Tab) to open the developer console. Then press `Ctrl+V` to paste the code. Press Enter. Close the console by pressing `~` again.

### Can I share my crosshair with friends?
Yes. The crosshair code is a short string of text. You can copy it and send it to anyone. They can paste it into their own game console.

### Why does the crosshair look different in the preview?
The preview is a rough approximation. The actual crosshair in Counter-Strike 2 will look slightly different due to game-specific rendering. Use the preview as a general idea of style and size.

## 🔧 Troubleshooting

**The page doesn't open**
Make sure you double-clicked the `index.html` file. If it opens in a text editor, right-click the file, select "Open with", and choose your web browser.

**The crosshair code doesn't work in the game**
Make sure you copied the entire code. Paste it exactly as shown. Do not add any extra spaces or characters.

**The preview shows nothing**
Try refreshing the page. If the issue continues, close and reopen the file.

**The "Copy" button doesn't work**
Copy the code manually by selecting the text and pressing `Ctrl+C`.
